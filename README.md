# シフト管理

留学生向けシフト管理アプリの段階的な開発プロジェクトです。

現在は仕様書 v0.4 の受入条件1〜18と、受入条件19の8言語切り替えを実装しています。

## 実装済み

- 月間カレンダーの表示
- 任意の日付への複数シフト登録
- 1日5件の登録上限
- バイト名の任意入力
- 勤務開始時刻順の自動ソート
- 開始時刻、終了時刻、休憩①～⑤の開始時刻と終了時刻から実勤務時間を計算
- 休憩①を常時表示し、＋・－ボタンで休憩②～⑤を追加・削除
- 時刻を時2桁・分2桁でキーボード入力し、入力完了後に次の項目へ自動フォーカス
- 日を跨ぐシフトを開始日のシフトとして表示
- カレンダーの日付セルへ当日登録分の実勤務合計を `hh:mm` で表示
- 時給の任意入力と、未入力時の概算給料0円計算
- 日付選択後のシフト入力画面を閉じるボタン
- シフトの登録、編集保存、編集キャンセル後にシフト入力画面を閉じる
- 日付選択時に直前7日間の集計期間、登録済み勤務時間、今後勤務できる時間を表示
- 通常期間の勤務を開始日基準で集計する直前7日間28時間超過警告
- 登録済みシフトの編集と個別削除
- シフト管理と長期休み管理のタブ切り替え
- 長期休み名の任意入力と、長期休みの登録、編集、個別削除、開始日が新しい順の表示
- 長期休み期間の重複登録防止
- カレンダーの日付セル下部へ長期休み期間を淡い緑色の線で表示
- 長期休み開始日に7日間集計をリセット
- 長期休み期間の勤務を開始日基準で集計する直前7日間40時間超過警告
- 長期休み期間の日跨ぎ勤務を開始日に全量計上する1日8時間超過警告
- 長期休み終了翌日から通常期間の7日間集計を新しく開始
- 実勤務時間と時給からシフト別の基本賃金を計算
- 22:00〜翌05:00の実勤務時間へ25%の深夜割増を適用
- 深夜時間帯と重なる休憩①～⑤を深夜勤務時間から控除
- 時間外割増と休日手当を計算対象外として明示
- シフト単位で1円未満を四捨五入
- シフト別、日間、月間の概算給料を表示
- シフト別の概算給料内訳をボタンで展開表示
- 日跨ぎ・月跨ぎシフトの概算給料を開始日・開始月へ集計
- 日跨ぎを含むシフトの実時間重複を警告し、確認後は重複したまま保存可能
- 重複シフトに関係する開始日を黄色の警告セルで表示
- 重複シフトの日付選択画面へ黄色の重複周知を表示
- 1日上限、7日間上限、シフト重複の優先順で日付セルへ警告マークを1件表示
- 日付選択画面では発生中の1日上限、7日間上限、シフト重複をすべて表示
- 表示月の赤色警告日と法的問題の周知を月間概算給料の下へ表示
- 原因シフトの修正・削除後に黄色・赤色警告と月間周知を自動更新
- タブ行の右端に常時「Language」と表示する言語選択ボタンを配置
- 言語選択モーダルでは日本語、英語を先頭に固定し、それ以降を言語名のローマ字順で表示
- 静的文言と操作後に生成される文言を日本語、英語、ベンガル語、韓国語、ミャンマー語、ネパール語、シンハラ語、ベトナム語へ切り替え
- シフト・長期休み登録フォームの必須入力、時刻、年月日、時給の警告文を対応8言語へ切り替え
- 言語情報、各言語の翻訳、切り替え処理を `lang` フォルダーへ分離

登録データは画面を開いている間だけ保持します。ブラウザへの保存はまだ実装していません。
休憩なしの場合は、休憩開始時刻と休憩終了時刻を両方空欄にします。

## 確認方法

依存ライブラリ、インストール、ビルド、開発サーバーは不要です。

ルートにある `index.html` をダブルクリックしてブラウザで開いてください。

## 現在のファイル

- `index.html`: 画面構造
- `styles/calendar.css`: デザインとレスポンシブ表示
- `styles/long-breaks.css`: 管理タブ、長期休み一覧、入力画面、カレンダー上の期間線
- `styles/pay.css`: シフト別、日間、月間の概算給料と内訳表示
- `styles/warnings.css`: 黄色・赤色の警告レベルと月間の法的問題周知
- `styles/language.css`: Languageボタン、言語選択モーダル、言語一覧
- `lang/languages.js`: 対応言語の情報と表示順
- `lang/ja.js`、`lang/en.js`、`lang/bn.js`、`lang/ko.js`、`lang/my.js`、`lang/ne.js`、`lang/si.js`、`lang/vi.js`: 対応8言語の翻訳文言
- `lang/language.js`: 言語選択と画面への翻訳反映
- `scripts/work-limit.js`: 開始日基準の7日間集計、暦日基準の1日集計、期間リセット、勤務時間上限判定
- `scripts/break-time.js`: 休憩①～⑤の検証、合計休憩時間、実勤務時間の計算
- `scripts/calendar.js`: カレンダー生成、シフトと長期休みの登録・編集・削除、概算給料計算、登録上限、並び順、警告表示、動的文言の言語切り替え
- `tests/work-limit.test.js`: 勤務時間上限判定の境界値確認
- `tests/break-time.test.js`: 休憩①～⑤の合計、空欄、重複、日跨ぎ、上限確認
- `Reference/`: 仕様書と参照資料

## GitHub Pagesでの公開

1. このフォルダーをGitHubリポジトリへ登録します。
2. GitHubのリポジトリで `Settings` → `Pages` を開きます。
3. `Source` に `Deploy from a branch` を選択します。
4. ブランチに `main`、フォルダーに `/(root)` を選択して保存します。

HTML、CSS、JavaScriptをそのまま公開するため、GitHub Actionsによるビルドは不要です。

ブラウザ保存、オフライン対応などはまだ実装していません。
