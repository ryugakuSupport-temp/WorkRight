# シフト管理PWA

留学生向けシフト管理アプリの段階的な開発プロジェクトです。

現時点では、仕様書 v0.4 の受入条件1「月間カレンダーを表示できる」のみを実装しています。

## 実装済み

- 当月の月間カレンダー表示
- 前月・翌月への移動
- 今日の月へ戻る操作
- 今日と月外日、日曜、土曜の視覚的な区別
- スマートフォン、タブレット、PC向けレスポンシブ表示

シフト登録、勤務時間・給料計算、警告、保存、多言語対応など、受入条件2以降の機能は未実装です。

## 開発

Node.js 22.13以上と pnpm を使用します。

```bash
pnpm install
pnpm dev
pnpm build
pnpm test
```

仕様書は `Reference/shift-management-pwa-spec-v0.4.md` を参照してください。
